Clean Code

Conceptos:

- camelCase (cC): Toda palabra en minuscula. Si se compone de 2 o mas, la inicial contando desde la segunda SIEMPRE será en mayúscula.

- Pascal Case (PP): Toda inicial de cada palabra SIEMPRE va en mayúscula.

- snake_case (s_c): Toda la palabra se escribe en minúscula sostenido, y se separa con un guión bajo.

- kebab-case (k-c): Es basicamente igual al snake_case y la unica diferencia es que el guión va en el medio.

1. Camel Case Se utiliza para:
   -Funciones
   Ejm:proyecto, proyectoIntroducción, proyectoIntroduccionUno

2. Pascal Case se utiliza para:
   -Clases (POO)
   -Componentes
   Ejm: Persona, MenuPrincipal

3. snake_case se utiliza para:

- Variables
- Clases CSS
  Ejm: nombre, nombre_completo

4. Kebab-case se urtiliza para:

- carpetas
  -archivos
  -clases CSS
  Ejm: proyecto, proyecto-introduccion
