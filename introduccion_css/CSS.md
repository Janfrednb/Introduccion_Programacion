2.  Codigo Interno : Se escribe dentro de la etiquetas (No se puede hacer)
3.  Condigo Externo : Se cre en otro archivo aparte (El correcto de clean code)

Box Model contiene: tener en cuenta que si el box model cuenta con 1200px el contenido no puede superar ese valor porquue se desborda

2. Margen => Margin
3. Relleno => Padding
